# Festiva - Gestor de Festival Musical

## Descripción

Aplicación de una sola página hecha con React, TypeScript, Vite y Tailwind CSS
para registrar, visualizar, marcar como favoritas, eliminar y consultar las
presentaciones de un festival musical. La información se conserva en localStorage.

## Cómo ejecutar el proyecto

1. Instalar las dependencias:

   npm install

2. Iniciar el servidor de desarrollo:

   npm run dev

3. Abrir en el navegador la dirección que aparece en la terminal (normalmente http://localhost:5173/).

## Requisitos

- Node.js y npm instalados

## Funcionalidades

- Lista de presentaciones con estados de disponibilidad (Disponible, Pocos espacios, Agotado)
- Favoritos, eliminación y modal de detalle (se cierra con botón y con Escape)
- Formulario controlado con validaciones
- Persistencia con localStorage
- Mejora creativa: resumen estadístico y barra de ocupación
